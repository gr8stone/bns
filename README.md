---

## 🏛️ Brand & Institutional Model

Budget Ndio Story operates under a sustainable **Two-Entity Model**:

- **BNS Foundation**: Non-profit civic entity dedicated to youth budget literacy, grassroots ward-level scorecards, county listening sessions, and data journalism capacity building across all 47 counties.
- **BNS Studios**: Commercial impact production studio executing commissioned research storytelling, documentary films, podcasts, animations, and civic campaigns for development partners, MDAs, and think tanks.
- **≥ 40% Fiduciary Covenant**: Under an institutional covenant, BNS Studios transfers at least 40% of its annual net operational profits directly to BNS Foundation to permanently fund independent civic oversight.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/gr8stone/bns.git
cd bns
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) to view the application in your browser.

### 4. Build for production
```bash
npm run build
```

### 5. Preview production build
```bash
npm run preview
```
